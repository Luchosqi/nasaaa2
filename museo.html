Museum QR cards

Print these cards and place them around a room. Each QR code opens one mission directly on a phone or tablet. With the local server in LAN mode, it works without internet: the phones only need to join the same Wi-Fi network as the computer serving the site.

Offline room: run node tools/serve.cjs --lan (or iniciar.cmd --lan) and open this page from the network address it prints, so the codes point at that computer. Online: use the published address.
